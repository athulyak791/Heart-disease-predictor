**HeartAI Diagnostics**
A lightweight Machine Learning web application that predicts heart disease risk using patient clinical data.

**_Tech Stack_**
Engine: Python, Scikit-Learn (KNN Classifier)
Web: Flask, Bootstrap 5
Data: Pandas, NumPy, StandardScaler


** Key Features**
Automated Preprocessing: Handles One-Hot Encoding and Scaling in real-time.
Responsive UI: Clean, industrial-themed dashboard for patient vitals entry.
Instant Result: Provides immediate classification (Detected/Not Detected).


** Installation**
git clone [https://github.com/YourUsername/heart-disease-prediction.git](https://github.com/YourUsername/heart-disease-prediction.git)
